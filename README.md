# Superredstone

Hi, my name is Patrick Canal 👋

I'm passionate about open-source, Linux (I use NixOS, btw), and developer tooling. I enjoy building and customizing tools that improve my workflow and productivity.

The projects I’m most proud of are:
- [nixos](https://github.com/Superredstone/nixos) – My personal NixOS configuration, focused on reproducibility, performance, and clean system management.
- [nixvim](https://github.com/Superredstone/nixvim) – My customized Neovim setup, built with Nix for a fully declarative and reproducible development environment.
- [spotiflac-cli](https://github.com/Superredstone/spotiflac-cli) – A command-line tool for downloading songs from Spotify.
- [dracula/new-tabs](https://github.com/dracula/new-tabs) - A theme for the new tab page on Chrome and Firefox, based on the Dracula color palette.
